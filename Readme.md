# Сайт препарата «Димолегин®»
Многостраничный коммерческий адаптивный веб-сайт (13 стр) препарата Димолегин®. Проект реализован на чистом HTML5/SASS и JavaScript с семантической версткой.

## 🛠 Технологический стек

### Frontend
- **HTML5** — семантическая верстка, БЭМ-методология
- **SASS/SCSS** — модульная структура, сброс стилей, переменные, медиа-запросы
- **JavaScript** — работа с DOM, обработка событий

### Библиотеки и плагины
- **Swiper** — слайдер
- **AOS** — анимации при скролле

## 🎯 Ключевые функции

### UI/UX элементы
- Плавная навигация по странице
- Адаптивное бургер-меню для мобильных устройств
- Переключатель языка
- Адаптивные карусели описания препарата
- Аккордеон для мобильной версии описания препарата
- Интерактивный таймлайн с анимацией через AOS
- Поиск по клиническим исследованиям
- Модальное окно с верификацией медицинского статуса
- Модальное окно Подать заявку на участие в Клинических Исследованиях

## 🔧 Технические особенности

### Адаптивность
- Адаптивный дизайн
- Медиа-запросы
- Кросс-браузерная совместимость


**Проект демонстрирует навыки разработки коммерческих многостраничных веб-сайтов на чистом HTML5/SASS и JavaScript с адаптивным дизайном, интерактивными элементами в медицинской сфере с соблюдением всех нормативных требований.**
